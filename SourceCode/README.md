# Source Code - BaiTap1
## Project
BaiTap1
## Description
Ứng dụng Android được xây dựng bằng Kotlin và Jetpack Compose,
mô phỏng giao diện thông tin cá nhân theo yêu cầu của bài tập tuần 1, câu 3.
## Input
- Thông tin họ và tên sinh viên.
- Mã số sinh viên.
- Hình ảnh đại diện.
- Các thành phần giao diện theo mẫu 
## Handle
- Khởi tạo ứng dụng Android bằng Kotlin và Jetpack Compose.
- Xây dựng giao diện thông tin cá nhân.
- Định dạng và sắp xếp các thành phần giao diện theo mẫu.
- Hiển thị hình ảnh đại diện từ tài nguyên của ứng dụng.
- Chạy và kiểm tra giao diện trên Android Emulator.
## Output
Ứng dụng hiển thị giao diện thông tin cá nhân trên Android Emulator, bao gồm:
- Hình ảnh đại diện.
- Họ và tên: Thái Thanh Trúc
- MSSV: 084306002719
- Các thành phần giao diện được bố trí theo mẫu yêu cầu.
## Technologies
- Kotlin
- Android Studio
- Jetpack Compose
- Github
## How to run
1. Mở thư mục `SourceCode` bằng Android Studio.
2. Chờ Gradle Sync hoàn tất.
3. Khởi động Android Emulator.
4. Nhấn Run để chạy ứng dụng.
## Main Screen
Ứng dụng hiển thị:
- Nút quay lại.
- Nút chỉnh sửa.
- Ảnh đại diện.
- Họ tên sinh viên.
- Mã số sinh viên.
